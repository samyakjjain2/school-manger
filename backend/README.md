# School Management Backend - Stage 2

This is the backend API directory for the School Management System, initialized with Node.js, Express, and Prisma.

## Folder Structure

```text
backend/
├── node_modules/       - Project dependencies
├── prisma/             - Database schema and configuration
│   └── schema.prisma   - Prisma configuration schema file
├── src/                - Application source code (empty in Stage 2)
├── .env                - Environment configuration variables (ignored in Git)
├── .gitignore          - Version control ignore rules
├── package.json        - Node package configuration
└── README.md           - Documentation (this file)
```

## Running the Dev Server

Currently configured in Stage 2 with start and reload script configuration. To run nodemon development mode in Stage 3:
```bash
npm run dev
```
